# WeedOut

An ultra-quick vibe coded side project: a single-page, French-language app to track daily cannabis consumption and help reduce it over a 12-week program.

## What it does

- **Suivi quotidien** — one form per day: impulsive daytime urges (with a "20-minute protocol" to delay the decision), planned evening activities, evening consumption, nighttime consumption, and general state (mood, motivation, sleep, fatigue).
- **Bilan hebdo** — rolling 7-day or calendar-week stats: quantity consumed, impulse-management counts, and average mood/motivation/sleep/fatigue.
- **Mes données** — export/import your data as JSON, or wipe it.

All data is stored locally in the browser (`localStorage`), nothing leaves the device.

## Files

- `index.html` — the whole app (HTML/CSS/JS, no build step, no dependencies).
- `rules.txt` — the French methodology/worksheet this app is based on (12-week program and personal rules).

## Usage

Just open `index.html` in a browser.
